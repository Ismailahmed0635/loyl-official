# brain.md — Project Memory

## 1. Project Summary
- Loyl is a digital loyalty & stamp card platform for Bangladesh merchants (cafés, salons, gyms, restaurants).
- Merchants create offers, generate QR posters, and track customer visits. Customers scan QR, collect stamps, redeem rewards — no app download.
- Platform: web app (mobile-first, desktop-responsive)
- Business model: SaaS subscription for merchants; free for customers

## 2. Tech Stack
- Framework: Next.js 14 (App Router)
- Styling: Tailwind CSS
- Animation: Framer Motion + canvas-confetti
- Icons: Lucide React
- Language: TypeScript
- Font: Inter (Bangla fallback: Hind Siliguri)

## 4. Design Rules (non-negotiable)
- Border radius: **8px inputs (`rounded-input`), 16px cards (`rounded-card`), 24px panels
  (`rounded-panel`), 9999px pills**. Legacy `rounded-input` was 12px — remapped in
  `tailwind.config.ts`; do not reintroduce per-page radii.
- Type scale: `text-display-lg` 48/56 · `text-headline-lg` 32/40 · `text-headline-md` 24/32 ·
  `text-headline-sm` 18/26 · `text-metric-num` 28/32 · `text-body-lg|md|sm` 16|14|12 ·
  `text-label-lg|md|sm` 14|12|11. Pair `font-<role>` with `text-<role>` (e.g.
  `font-headline-sm text-headline-sm`). Always add `font-*` — the size token alone leaves the
  family on the default sans.
- Shadows: `shadow-ambient` (raised/interactive), `shadow-hairline` (resting cards),
  `shadow-inset-light` (primary buttons), `shadow-frost` (floating chrome). Hairline borders
  over heavy drop shadows.
- Tap targets: minimum 44px on mobile (`min-h-[44px]` is already on `Button`).
- Motion: Framer Motion only, recipes from `lib/motion/variants.ts`. No CSS animations except
  prefers-reduced-motion fallbacks.
- Colour semantics (unchanged, restated for the new tokens):
  - Green (`brand-green` / `primary-container`) = primary actions & positive metrics
  - Wine (`brand-red` / `wine`) = urgent/expiring/destructive **and** redemption
  - Amber = scratch cards & offers only
  - `outline` / `hairline` = structure only, never a status
- Semantics map to the Stitch class names 1:1 (`bg-surface-container-lowest`,
  `text-on-surface`, `text-on-surface-variant`, `border-hairline`, `bg-primary-container`) —
  port screens with those classes rather than inventing new ones.
- Utilities in `app/globals.css`: `.tnum` (tabular figures for metrics/counters), `.frost`
  (backdrop-blur for floating header + bottom nav).
- Bangla numerals optional; English default

## 5. Code Rules
- 'use client' on any file using motion or hooks
- Animation recipes live in lib/motion/variants.ts — never inline unless unique
- Tailwind only — no CSS modules, no styled-components
- Mobile-first: base styles for 375px, then sm/md/lg breakpoints
- Every page wrapped in container: max-w-md mx-auto md:max-w-2xl lg:max-w-6xl
- Accessibility: useReducedMotion hook on every animated page
- No placeholder animations — every animation must be in motion spec or explicitly requested
